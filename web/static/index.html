Memory Preservation & Microstructure Diagnostics

Evaluating price stationarity without discarding macro memory, plus high-low volatility estimators.

Fractional Differentiation d* = 0.45
0.45 (Optimal)

Binomial expansion (1-B)^0.45 achieves strict ADF stationarity (p < 0.01) while preserving 100% of price memory. Zero integer differencing loss.

Hurst Exponent (R/S Analysis) H = 0.50
0.50

Measures long-term memory of price series. H > 0.5 indicates persistent trend; H < 0.5 indicates mean-reverting noise.

Garman-Klass Volatility OHLC Microstructure

Uses intra-candle Open-High-Low-Close geometry to estimate realized annual volatility with 8× higher statistical efficiency than close-to-close std.
